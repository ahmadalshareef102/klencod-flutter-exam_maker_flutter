# صانع الاختبارات الذكي (Flutter)

## قبل البناء
1. ضع الخطين في `assets/fonts/`:  `Cairo-Regular.ttf` و `Cairo-Bold.ttf`.
2. ارفع المشروع إلى GitHub؛ سيبني workflow ملف APK تلقائيا (Actions > exam-maker-apk).
   (الـ workflow ينشئ مجلد android تلقائيا بالأمر flutter create).

## المرحلة الحالية
- محرر الأسئلة + قوالب جاهزة + شريط رموز رياضية
- ترويسة رسمية قابلة للتعديل، عمودان، ورقة طالب / نموذج إجابة محلول
- استيراد كشف الطلاب من Excel (ورقة مستقلة لكل طالب + QR)
- ورقة تظليل OMR
- التصدير: PDF (طباعة / حفظ / مشاركة)

## المرحلة القادمة
- كيبورد رياضيات كامل (كسور/جذور/عمليات عمودية)
- التصحيح الآلي بالكاميرا لورقة OMR
- تصدير Word، تفعيل بمفتاح
